# hongbo.github.io



personal website for blog writing

how to write a blog with hexo?

Local setup: install Node.js and Pandoc, then run `npm ci`. The project uses
`hexo-renderer-pandoc` for new Markdown posts.

## Writing

run in local brower (development mode)

```bash
$ hexo server
```

build
```bash
$ hexo generate
```

deploy
```bash
$ hexo deploy
```
